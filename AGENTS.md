# Premium Assessoria Imobiliária

## Escopo do projeto

- Este repositório contém o site institucional estático da Premium Assessoria Imobiliária.
- Preserve a identidade visual, a responsividade, a acessibilidade e o funcionamento existente.
- Mantenha as alterações limitadas ao pedido do usuário e não faça refatorações sem necessidade.
- O domínio de produção é `https://assessoriapremium.com.br`.

## Validação

- Antes de concluir uma alteração, revise o diff e verifique referências de arquivos, links e recursos modificados.
- Quando a mudança afetar a interface, valide a apresentação em tamanhos de tela desktop e móvel sempre que houver uma forma de visualização disponível.
- Não publique arquivos temporários, credenciais, chaves privadas, tokens ou segredos.

## Git e autoria

- Use a identidade local `Deborah Luiza <deborahluiza.dl@gmail.com>` para novos commits; a responsável no GitHub é `deborahluiza1`.
- Use mensagens no padrão Conventional Commits, como `feat:`, `fix:`, `docs:`, `style:`, `refactor:` e `chore:`.
- Não reescreva o histórico publicado e não use comandos destrutivos sem autorização explícita.
- Não faça commit nem push de alterações que não pertençam ao pedido atual.

## Publicação

- Trate pedidos explícitos como “publicar”, “subir”, “fazer push” ou equivalentes como autorização para criar o commit necessário e enviá-lo para `origin/main`.
- Sem um pedido explícito de publicação, deixe as alterações locais e informe o que está pendente.
- Antes do push, confirme que o diff está correto e que não há arquivos inesperados.
- Depois do push, confirme que o commit chegou ao GitHub e acompanhe a execução de GitHub Actions associada quando o acesso estiver disponível.
- Aguarde o workflow finalizar e informe sucesso ou falha. Em caso de falha, examine os logs e corrija apenas problemas relacionados ao pedido; solicite orientação antes de ampliar o escopo.
- Quando o deploy for concluído, informe o commit publicado e o endereço de produção.
